# 参考资料

- [MedRAX: Medical Reasoning Agent for Chest X-ray](https://arxiv.org/abs/2502.02673)：胸片工具协作与 ChestAgentBench。
- [MedAgent-Pro](https://arxiv.org/abs/2503.18968)：医学知识检索与多模态诊断流程。
- [Lingshu](https://arxiv.org/abs/2506.07044)：项目使用的医学视觉语言模型；[32B 模型卡](https://huggingface.co/lingshu-medical-mllm/Lingshu-32B)。
- [TorchXRayVision](https://github.com/mlmed/torchxrayvision)：胸片分类和解剖区域分割工具。

本项目是独立应用实现，不复现上述论文的全部工具或评测协议。论文中的成绩与本仓库的公开小样本选择题结果不直接可比。
